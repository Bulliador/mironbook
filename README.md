# Twilight Quest Bot — v0.1

Первая версия бота для книжного квеста.

## Что уже умеет

- девушка пишет боту;
- её сообщение копируется в твой личный чат с ботом;
- ты нажимаешь Reply на её сообщение;
- твой ответ приходит ей от имени бота;
- работают не только тексты, но и многие типы сообщений, которые Telegram умеет копировать;
- маршруты Reply хранятся в SQLite, поэтому не пропадают после перезапуска.

## 1. Создай бота

Открой Telegram → `@BotFather` → `/newbot`.

BotFather попросит:
1. отображаемое имя;
2. username, который обязательно заканчивается на `bot`.

Именно username можно потом написать на открытке.

Сохрани выданный Bot Token и никому его не отправляй.

## 2. Установи Python

Рекомендуется Python 3.11+.

В папке проекта:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Потом:

```bash
pip install -r requirements.txt
```

## 3. Создай `.env`

Скопируй `.env.example` в `.env`.

Сначала можно оставить:

```env
ADMIN_ID=0
```

и вставить только BOT_TOKEN.

## 4. Узнай свой Telegram ID

Запусти:

```bash
python bot.py
```

Открой своего бота и отправь:

```text
/id
```

Он покажет твой числовой Telegram ID.

Останови бот (`Ctrl+C`), впиши ID в `.env`:

```env
ADMIN_ID=123456789
```

и снова запусти:

```bash
python bot.py
```

## 5. Как пользоваться

Когда другой человек пишет боту, тебе приходит карточка с его именем/ID и само сообщение.

Нажми **Reply** именно на это сообщение (или на карточку пользователя) и напиши ответ.

Бот отправит твой Reply тому человеку **от своего имени**.

## 6. Как проверить до квеста

Лучше всего написать боту со второго Telegram-аккаунта или попросить доверенного друга.

Тест:
1. второй аккаунт → `/start`;
2. написать `Привет`;
3. сообщение должно прийти тебе;
4. ты отвечаешь Reply;
5. второй аккаунт получает ответ от бота.
